# 智慧校园电子班牌系统 (CampusScreen)

## 项目概述

智慧校园电子班牌系统是一个基于Android平台开发的综合性校园信息展示与管理系统。该系统专为华东交通大学通信电子创新基地设计，集成了基地动态展示、项目管理、文化传承、人员培养、设备管理、安全保障等多个功能模块，旨在打造一个现代化、智能化的校园信息服务平台。

## 技术架构

### 开发环境
- **开发语言**: Java
- **开发平台**: Android
- **最低SDK版本**: API 30 (Android 11)
- **目标SDK版本**: API 34 (Android 14)
- **编译SDK版本**: API 34

### 核心技术栈
- **UI框架**: Material Design 3
- **网络请求**: OkHttp 4.12.0
- **图片加载**: Glide 4.16.0
- **布局管理**: ConstraintLayout, RecyclerView
- **动画效果**: ViewPager2, ObjectAnimator
- **Web组件**: WebView

### 项目结构
```
com.example.campusscreen/
├── MainActivity.java              # 主界面Activity
├── ProjectDetailActivity.java     # 项目详情Activity
├── ManagementDetailActivity.java  # 管理办法详情Activity
├── WebViewActivity.java          # Web浏览Activity
├── ScanCheckinActivity.java      # 扫码签到Activity
├── EmergencyHelpActivity.java    # 紧急求助Activity
├── CultureFragment.java          # 基地文化Fragment
├── CultivationFragment.java      # 人才培养Fragment
└── 其他支持类和适配器
```

## 核心功能模块

### 1. 基地动态 (首页)
- **实时时间显示**: 显示当前时间、日期和星期
- **天气信息**: 集成高德地图API，实时获取南昌地区天气数据
- **项目轮播**: 展示基地重点项目，支持自动轮播和手动切换
- **重要通知**: 显示基地重要公告和通知信息
- **名言金句**: 定期更新励志名言，营造积极学习氛围

### 2. 消息通知
- **通知分类**: 支持学术讲座、竞赛信息、基地活动等多种类型
- **消息详情**: 点击查看详细通知内容
- **时间管理**: 显示通知发布时间和重要程度

### 3. 设备中心
- **设备展示**: 展示基地各类实验设备和仪器
- **设备管理**: 设备状态监控和使用记录
- **预约系统**: 支持设备预约和使用申请

### 4. 项目展示
- **项目分类**: 按照科技创新、产学合作等类别展示项目
- **项目详情**: 详细展示项目技术特点、应用价值、获奖情况
- **团队信息**: 显示项目负责人、团队规模、指导教师等信息
- **成果展示**: 展示项目取得的成绩和社会影响

#### 重点项目案例
1. **基于物联网技术的智慧蔬菜大棚监测系统**
2. **点滴卫士——智慧输液报警系统**
3. **术影无踪——OpenCV双目视觉智能手术调光系统**
4. **光明之路——一种"开源节流"型路灯**
5. **声纹哨兵——城市噪声污染AI监测与治理系统**
6. **聆途睿行——基于多模态人机交互的智慧导盲系统**

### 5. 安全须知
- **安全规范**: 实验室安全操作规程
- **应急预案**: 紧急情况处理流程
- **安全培训**: 安全知识学习和考核
- **紧急求助**: 一键紧急联系功能

### 6. 基地介绍
- **基地概况**: 通信电子创新基地发展历程和现状
- **组织架构**: 基地管理团队和组织结构
- **发展规划**: 未来发展目标和规划

### 7. 人才培养
- **培养目标**: 明确的人才培养定位和目标
- **培养方向**: 软件开发、硬件设计等专业方向
- **培养模式**: "TBL-CDIO"教学方法和阶梯型学习模式
- **成果展示**: 培养成果和优秀学员展示

### 8. 基地文化
- **文化理念**: "四个YU"文化体系
  - **授人以鱼**: 给予资源，传授知识
  - **授人以渔**: 授予方法，培养能力
  - **授人以欲**: 激发欲望，培养动力
  - **授人以寓**: 感悟人生，培养格局
- **文化传承**: 基于《弟子规》等传统文化的现代诠释
- **行为准则**: "三学三加两保持一初心"的行为指导
- **团队精神**: "链条文化"的团队协作理念

### 9. 基地管理
- **管理制度**: 完善的基地管理规章制度
- **成员管理**: 基地成员考核和管理办法
- **项目管理**: 项目立项、执行、验收全流程管理
- **资料设备管理**: 设备和资料的规范化管理
- **日常事务管理**: 值班、卫生、安全等日常事务
- **基金使用管理**: 基金申请、审批、使用、报销流程
- **校外导师管理**: 校外导师聘任和管理制度
