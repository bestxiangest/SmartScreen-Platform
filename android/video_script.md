# 智慧校园电子班牌系统 - 视频演示稿

---

**(视频开始)**

**【开场画面】**
*   **镜头**: 特写电子班牌的整体外观，然后缓缓推近，清晰展示APP的主界面 (`fragment_home`)。
*   **配音 (沉稳、大气)**: (背景音乐起) 欢迎来到我们的智慧校园电子班牌系统。这不仅仅是一块屏幕，更是融合了信息展示、智能管理与AI赋能的综合性校园服务平台。

**【第一部分：首页 - 信息聚合中心】**
*   **镜头**:
    1.  手指在屏幕左侧导航栏 ([`activity_main.xml`](app/src/main/res/layout/activity_main.xml:1)) 上滑动，展示“基地首页”、“基地介绍”等九个导航按钮。
    2.  镜头聚焦在右侧首页内容区。
*   **配音**: “系统主界面采用现代化设计，左侧是功能导航栏，右侧是信息聚合的动态首页。在这里，我们可以一目了然地看到……”
*   **镜头**:
    1.  特写“基地优秀项目成果轮播图” (`projects_carousel`)，并手动点击左右按钮，切换几张项目图片。
    2.  镜头移动到右侧的“天气状况”模块，展示实时天气信息。
    3.  镜头向下移动到“重要通知” (`important_notices_container`)，并滑动列表，展示多条通知。
    4.  最后，镜头停在底部的“快速入口”按钮上。
*   **配音**: “……最新的项目成果、实时的天气信息、滚动的重要通知，以及便捷的快速入口。所有核心信息，一触即达。”

**【第二部分：核心功能模块展示】**
*   **镜头**: 点击左侧导航栏的“基地介绍”。
*   **配音**: “接下来，让我们深入探索系统的各项功能。首先，进入‘基地介绍’模块。”
*   **镜头**:
    1.  展示“基地介绍”页面 (`fragment_introduction`)，缓慢向上滑动，依次掠过“基地简介”、“培养模式”、“成果介绍”和“基地文化”这几个图文并茂的卡片。
*   **配音**: “在这里，我们通过详实的图文内容，全面展示了基地的发展历程、人才培养模式、丰硕的科研成果以及深厚的文化底蕴。”

*   **镜头**: 点击导航栏的“消息通知”。
*   **配音**: “‘消息通知’模块是信息发布的重要窗口。”
*   **镜头**:
    1.  展示“消息通知”页面 (`fragment_schedule`)，特写顶部的统计数据。
    2.  点击其中一个消息项的“展开详细内容”按钮，展示其完整内容。
    3.  再次点击，收起内容。
    4.  点击“下一页”按钮，演示翻页功能。
*   **配音**: “这里不仅汇总了所有通知，还提供了分类统计和便捷的交互体验。用户可以轻松展开查看详情，并通过翻页浏览历史消息。”

*   **镜头**: 点击导航栏的“设备中心”。
*   **配音**: “对于实验室而言，设备的高效管理至关重要。我们的‘设备中心’模块提供了完美的解决方案。”
*   **镜头**:
    1.  展示“设备中心”页面 (`fragment_equipment`)，镜头扫过顶部的设备总数、可用、使用中等统计卡片。
    2.  镜头向下移动，展示按类别划分的设备网格。
    3.  特写一两个设备卡片，突出其彩色的“可用”和“使用中”状态标签。
    4.  最后，手指点击右上角的“预约设备”按钮，可以简单示意弹出一个预约界面（或直接解说）。
*   **配音**: “系统实时监控所有设备的状态，并通过醒目的颜色标签进行区分，一目了然。师生可以方便地在线浏览和预约所需设备，极大地提高了设备利用率。”

*   **镜头**: 点击导航栏的“项目展示”。
*   **配音**: “基地的创新活力与科研实力，在‘项目展示’模块中得到了淋漓尽致的体现。”
*   **镜头**:
    1.  展示“项目展示”页面 (`fragment_projects`)，特写顶部的项目统计数据。
    2.  镜头聚焦在获奖项目网格，逐一展示几个色彩鲜艳、设计精美的项目卡片。
    3.  手指点击其中一个卡片的“查看详细”按钮。
    4.  镜头向下，展示“发明专利”和“计算机软著”区域的证书图片。
*   **配音**: “这里不仅是成果的陈列窗，更是荣誉的殿堂。我们集中展示了历年的获奖项目、发明专利和软件著作权，激励着每一位创新者不断前行。”

**【第三部分：AI赋能 - 核心亮点功能】**
*   **配音**: “现在，让我们进入最激动人心的部分——由尖端AI技术驱动的三大核心功能。”

*   **场景1: AI人才培养**
    *   **镜头**: 点击导航栏的“AI人才培养”，进入 (`fragment_ai_cultivation_modern`) 页面。
    *   **配音**: “首先是‘AI人才培养’。传统培养方案千人一面，而我们，为每一位学生量身定制。”
    *   **镜头**:
        1.  在表单中快速输入一位虚拟学生的信息（姓名、年龄、专业、兴趣方向等）。可以配合字幕突出输入的内容。
        2.  点击“方案生成”按钮 (`btn_generate_plan_modern`)。
        3.  特写加载动画和提示文字：“AI正在为您生成专属培养方案...”。
        4.  等待几秒后，结果展示区 (`layout_plan_display_modern`) 出现。
        5.  缓慢滑动，依次展示“发展计划”、“学习资源”、“技能发展”等多个由AI生成的卡片内容。
        6.  最后，特写AI生成的分析图表。
    *   **配音**: “只需输入基本信息，我们强大的AI引擎便会深度分析，从发展规划到技能学习，从资源推荐到职业指导，生成一份独一无二的、高度个性化的培养方案，并以直观的图表形式呈现，真正实现因材施教。”

*   **场景2: AI项目评估**
    *   **镜头**: 点击导航栏的“AI项目评估”，进入 (`fragment_ai_evaluation_modern`) 页面。
    *   **配音**: “接下来是‘AI项目评估’。它能为创新项目提供科学、客观的决策参考。”
    *   **镜头**:
        1.  在表单中输入一个虚拟项目的核心信息（项目名称、简介、技术领域、预算等）。
        2.  点击“启动 AI 评估”按钮 (`btn_start_evaluation`)。
        3.  同样，特写加载动画。
        4.  评估结果出现后，逐一展示“技术可行性”、“商业价值”、“创新程度”、“市场前景”等卡片的评估结果。
        5.  最后点击“保存报告”或“分享结果”按钮，示意操作。
    *   **配音**: “AI将从技术、市场、商业等多个维度，对项目进行全面、深入的评估，生成一份详尽的分析报告，帮助团队规避风险，找准方向。”

*   **场景3: AI智能助手**
    *   **镜头**: 点击导航栏的“AI智能助手”，进入 (`fragment_ai_assistant`) 聊天界面。
    *   **配音**: “最后，我们还有一位全天候在线的‘AI智能助手’。”
    *   **镜头**:
        1.  在底部的输入框 (`et_message_input`) 中输入问题，例如：“请问5G毫米波通信系统项目获得了什么奖项？”
        2.  点击发送按钮，聊天界面中出现用户的提问气泡。
        3.  短暂等待后，出现AI的回答气泡，准确回答出项目获奖信息。
        4.  接着再问一个上下文相关的问题，例如：“这个项目的指导老师是谁？”
        5.  AI再次给出正确的回答。
        6.  最后可以演示点击麦克风按钮 (`btn_microphone`)，模拟语音输入。
    *   **配音**: “它就像一位博学的专家，能够理解上下文，随时回答关于基地、项目、技术、设备等任何问题，提供即时、准确的信息支持。”

**【结尾】**
*   **镜头**: 画面切回APP主界面，然后慢慢虚化，屏幕中央出现产品的Logo和名称“智慧校园电子班牌系统”。
*   **配音 (激昂、有力)**: “智慧校园电子班牌系统，以科技赋能教育，用智能引领未来。我们，正在重新定义校园信息交互的边界。感谢您的观看！”
