# 交接清单

> 本文档面向接手方，覆盖环境依赖、启动步骤、账号、已知限制与安全事项。

## 1. 交付内容

| 目录 | 内容 |
| --- | --- |
| `server/` | Flask 服务端（API + 管理后台模板 + 演示数据脚本 + 建表 SQL） |
| `android/` | 电子班牌 Android 客户端（RK3568 一体机，Android 11 / API 30） |
| `miniprogram/` | 微信小程序端（uni-app + Vue3） |
| `docs/` | 部署说明、交接清单 |

第三方参考资料（RK3568 开发手册、智能触控屏规格书、项目开发文档 PDF）体积较大，未放入仓库，随交接压缩包提供。

## 2. 环境依赖

| 组件 | 版本要求 | 说明 |
| --- | --- | --- |
| Python | 3.10+ | 服务端；`requirements.txt` 已固定主要版本 |
| MariaDB / MySQL | 10.6+ / 5.7+ | 字符集 `utf8mb4`，建表见 `server/mysql.sql` |
| Node.js | 18+ | 仅小程序端构建需要 |
| JDK | 17 或 21 | Android 构建（AGP 8.10 要求 17+） |
| Android SDK | Platform 34 + Build-Tools 35 | `compileSdk = 34` |
| HBuilderX / 微信开发者工具 | 最新 | 小程序端调试与发布 |

## 3. 服务端启动

```bash
cd server
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env          # 填写 MYSQL_PASSWORD / SECRET_KEY / JWT_SECRET_KEY
mysql -uroot -p -e 'CREATE DATABASE campusscreen DEFAULT CHARSET utf8mb4;'
mysql -uroot -p campusscreen < mysql.sql   # 可选：应用启动时也会 db.create_all()
python seed_demo_data.py      # 可选：灌入 22 张表演示数据
python run.py                 # http://0.0.0.0:5000
```

生产部署（gunicorn + systemd + 域名）见 `docs/部署说明.md`，关键配置：

- 入口：`run.py` → `app.create_app()`
- 管理后台：`http://<host>:5000/dashboard`（Vue 无关，服务端模板渲染）
- API 前缀：`/api/v1`
- 上传目录：`server/static/uploads`（需运行账号可写）

## 4. Android 端构建

```bash
cd android
cp local.properties.example local.properties
# local.properties 中填写：
#   sdk.dir=/path/to/Android/sdk
#   DASHSCOPE_API_KEY=sk-xxxx        （通义千问/DashScope 密钥，通过 BuildConfig 注入）
./gradlew :app:assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

需要改动业务地址时看这两处：

- 服务端 API：`app/src/main/java/com/example/campusscreen/AnnouncementApiService.java` 的 `BASE_URL`
- 第三方 DashScope：`QwenApiService` / `AiCultivationModernFragment` / `AiEvaluationModernFragment`，统一读 `BuildConfig.DASHSCOPE_API_KEY`

设备调试：RK3568 支持无线调试，`adb pair <ip>:<port>` + `adb connect`；USB 需走 OTG/调试口。

## 5. 小程序端构建

```bash
cd miniprogram
npm install
npm run dev:mp-weixin     # 产物 dist/dev/mp-weixin
```

1. 用微信开发者工具导入 `dist/dev/mp-weixin`；
2. `manifest.json` 的 `appid` 需替换为自有小程序 AppID；
3. AI 相关页面的密钥占位符：`pages/ai/ai.vue`（阿里云 AccessKey）、`pages/ai/talent.vue`、`pages/ai/evaluation.vue`（DashScope Key），把 `YOUR_*` 换成实际值，或改为从服务端代理转发，避免把密钥下发到客户端。

## 6. 账号与权限

| 角色 | 说明 |
| --- | --- |
| `admin` | 管理员，可增删改全部内容 |
| `teacher` | 指导教师，可管理公告、审批物料、指派维修 |
| `maintainer` | 设备管理员，处理维修工单、出入库 |
| `student` | 学生，查看公告、签到、申领物料 |

首次部署请立刻修改 `admin` 密码；`seed_demo_data.py` 创建的演示账号密码统一为占位值，需要在使用前重设。

## 7. 已知限制与待办

1. **维修工单写入接口**：`server/app/api/maintenance.py` 的创建/派单/完工仍按旧数据模型实现，字段与当前 `models.py` 不一致，前端只做只读展示，需要按 `fault_type / fault_description / solution_description / actual_completion` 重写。
2. **管理后台**：`系统设置` 仍为占位页；设备、物料、课程的增删改尚未在页面实现（公告、项目、用户、课程表已支持）。
3. **演示数据**：`seed_demo_data.py --force` 会清空业务表，生产环境慎用。
4. **环境监测数据**：当前为脚本生成的模拟数据，真实传感器上报接口已具备（`/api/v1/environmental/data` POST），需对接硬件。

## 8. 安全事项（重要）

以下密钥曾以明文形式存在于源码/文档中，**仓库已替换为占位符，但请务必轮换**：

| 密钥 | 原位置 | 处理建议 |
| --- | --- | --- |
| DashScope API Key（`sk-`） | Android 的 3 个 Java 文件、小程序 `pages/ai/*.vue`、`files/*.py` | 前往阿里云百炼控制台重新生成，旧 Key 作废 |
| 阿里云 AccessKey（`AKID...`） | 小程序 `pages/ai/ai.vue` | 立即在 RAM 控制台禁用并轮换 |
| Gemini API Key（`AIza...`） | 服务端根目录 `,env` 文件（已删除） | 轮换 |
| 数据库口令 / JWT 密钥 | `config.py`、`app.py` 默认值 | 改为环境变量并重新设置强口令 |

其他建议：管理后台 `/dashboard` 未做细粒度权限校验，暴露公网前建议加反向代理层认证或限制来源 IP；MySQL 不要对公网开放。
