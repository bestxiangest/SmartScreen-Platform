# AI 人才培养界面分析

## 1. 界面功能概述

“AI 人才培养” ([`pages/ai/talent.vue`](pages/ai/talent.vue)) 是一个旨在为用户提供个性化 AI 学习路径规划的交互式功能页面。它通过收集用户的基本信息、专业背景和学习目标，利用后端 AI 服务生成一份详尽的学习方案，并结合文生图技术将方案可视化，为用户提供直观、易懂的学习指导。

## 2. 核心业务流程

1. **用户信息收集**：

   * 界面提供一个表单，用于收集用户的**姓名、学历、年龄、专业、兴趣方向**（如机器学习、深度学习）和**学习目标**。
   * 在提交前，会对表单进行简单的非空验证。
2. **生成个性化培养方案**：

   * 用户点击“方案生成”按钮后，应用会向后端 API 发起请求。
   * 请求成功后，后端会返回一个包含详细学习计划的 JSON 对象。这份计划包括：
     * **发展计划**：推荐的专业方向、核心能力培养、学习路径（基础、中级、高级）。
     * **时间目标规划**：短期、中期、长期的学习目标。
     * **学习资源推荐**：在线平台、书籍、实践项目。
     * **技能发展**：技术技能、软技能、推荐认证。
     * **职业发展指导**：行业趋势、职业路径、准备建议。
     * **个性化建议**：根据用户情况分析优势、挑战和应对策略。
3. **学习方案可视化**：

   * 在获取到学习方案数据后，应用会将其关键信息整合成一段结构化的文本（Prompt）。
   * 接着，调用文生图（Text-to-Image）API，将这段文本作为输入，生成一张信息图表。
   * 这张图表直观地展示了个性化培养方案的各个方面，大大提升了信息的可读性和用户体验。
4. **结果展示与交互**：

   * 页面上会展示由后端返回的结构化学习方案文本内容。
   * 同时，展示由文生图 API 生成的可视化图表，并支持点击查看大图。
   * 提供了“开始学习”和“自定义方案”的按钮（目前为占位功能），为未来的功能扩展预留了空间。

## 3. 调用的 API

该界面主要调用了两个外部 API：

### 3.1. 培养方案生成 API

* **URL**: `http://sys.sharpcaterpillar.top:7878/api/study_plan`
* **方法**: `POST`
* **请求体 (Content-Type: application/json)**:
  ```json
  {
    "name": "string",
    "age": "string",
    "education": "string",
    "major": "string",
    "interests": "string",
    "study_objective": "string"
  }
  ```
* **功能**: 接收用户信息，通过后端 AI 模型分析，返回个性化的学习培养方案。

### 3.2. 文生图 API (阿里云通义千问)

* **功能**: 用于将结构化的学习方案文本转换成可视化图表。
* **生成请求 URL**: `https://dashscope.aliyuncs.com/api/v1/services/aigc/text2image/image-synthesis`
  * **方法**: `POST`
  * **Headers**:
    * `Authorization`: `Bearer YOUR_DASHSCOPE_API_KEY`
    * `X-DashScope-Async`: `enable`
  * **请求体**:
    ```json
    {
      "model": "wanx-v1",
      "input": {
        "prompt": "一个详细描述学习方案的字符串"
      },
      "parameters": {
        "n": 1
      }
    }
    ```
* **任务状态查询 URL**: `https://dashscope.aliyuncs.com/api/v1/tasks/{taskId}`
  * **方法**: `GET`
  * **Headers**:
    * `Authorization`: `Bearer YOUR_DASHSCOPE_API_KEY`
  * **说明**: 由于图片生成是异步的，前端通过轮询此接口来获取最终的图片 URL。当前设置是每 5 秒查询一次，最多查询 30 次。

## 4. 实现总结

“AI 人才培养”界面通过整合后端智能服务和前沿的 AIGC 技术，成功实现了一个高度自动化和智能化的个人学习规划工具。它不仅能提供深度定制的学习内容，还通过可视化的方式极大地优化了用户体验，是整个“智能班牌”应用中的一个亮点功能。
